# Proyecto Software Ágil

Este repositorio corresponde a la Guía de Laboratorio N.º 01 sobre metodologías ágiles vs. tradicionales y aplicación del Manifiesto Ágil.

## Contenido

- `comparativa.md`: cuadro comparativo y análisis de los tres casos.
- `manifiesto.md`: valores, principios y aplicación de principios ágiles al proyecto de comercio electrónico.
- `backend/`: espacio destinado a la API propuesta con FastAPI.
- `frontend/`: espacio destinado a la interfaz propuesta con Next.js.
- `docs/`: documentación complementaria del proyecto.

## Arquitectura propuesta

Cliente → Next.js → FastAPI → PostgreSQL
