# Documentación

Este directorio está destinado para la documentación técnica y de análisis del proyecto.

- **`arquitectura.md`**: Documenta la arquitectura preliminar propuesta (Next.js, FastAPI, PostgreSQL) y cómo esta separación facilita el trabajo bajo metodologías ágiles.
- **`analisis.md`**: Contiene la resolución de las preguntas de análisis y la investigación comparativa sobre marcos ágiles adicionales (Kanban, XP, ScrumBan).
